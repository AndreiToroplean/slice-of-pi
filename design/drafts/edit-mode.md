# Edit mode (draft)

What the play screen's edit mode edits, as settled with the owner. On edit mode, this file supersedes [roadmap.md](roadmap.md) and [lake-handoff.md](lake-handoff.md); where it's silent, they still hold.

## What it edits

- **Page margins.** One set of margins for every page and screen. Edit mode edits them directly. Nothing is ever in them, not even the season header.
- **Corner buttons.** They can't be moved on their own: they always sit snug against the page margins, so editing the margins moves them. Their size is edited.
- **Keypad.** It spans the column within the side margins, and its bottom always lies on the bottom page margin. Its top is edited. The gaps between keys are not.
- **Slots.** Their top, their bottom and a slot's width are edited. The gaps between them follow: a row of 10 always spans the keypad's width.
- **Tape.** Its top and bottom are edited, and so is the size of its words.
- **Season header.** Always centered. Its size is edited, and everything in it (the text, the year bar) scales with it.

## Tied together

- A tile on the tape has the same proportions as a slot.

## Before building it

Look for every other ratio or size that should be tied together, beyond those above, and settle them with the owner, so that this file specifies edit mode fully before any of it is built.
